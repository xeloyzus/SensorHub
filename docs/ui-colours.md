# UI colours

All three dashboard views use `app/static/css/palette.css`.

| Colour | Hex | Use |
| --- | --- | --- |
| White | `#FFFFFF` | Card and signage surfaces |
| Navy | `#051850` | Headings, values, mobile and overview navigation |
| Blue | `#09298B` | Links, buttons and chart lines |
| Forest green | `#24734D` | Sustainability accents and current/good indicators |

The blue values were sampled from the [University of Stavanger website](https://www.uis.no/nb)
on 1 November 2026. Forest green is an accent chosen for this project.
Pale blue/green surfaces provide subtle grouping. Amber and red remain
reserved for warning states, accompanied by text labels.

Navy, blue, forest green, muted text, amber and red each exceed 4.5:1 contrast
on white. Navigation uses white text on navy, with pale green for secondary
labels. Measurement values use navy rather than arbitrary metric colours.
QR images retain black modules on white for scanning.
